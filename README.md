# STEAM

Model code for STEAM (Superposition of Turbulon and Eddy Atmospheric Model), Chapter 5 of *Weather and Climate Without Fluid Mechanics* (Thomas D. DeWitt, PhD dissertation, University of Utah, 2026).

![STEAM-simulated clouds](paper/concept-figs/witness_small_c002_s0100_into_sun.png)

Fly through STEAM-simulated clouds in the browser: [thomasddewitt.com/soar](https://thomasddewitt.com/soar).

The analysis code is in [turbulon-analysis](https://github.com/thomasdewitt/turbulon-analysis).
